Privacy and storage

Polaroid Studio runs in local-only mode. Photos and projects are stored in this browser (IndexedDB) and are never uploaded. The camera is only requested when you press the camera button. Uploads are limited to JPG, PNG, WebP and GIF files up to 15 MB each.

To keep a copy, open the Gallery and use the backup button on a project to save it as a file.

Accounts, cloud sync and sharing Not set up

This version has no sign-in, cloud storage or share links, and no button pretends otherwise. To add them, host the app yourself and connect a backend:

  1. Create a Supabase (or PostgreSQL) project with a projects table and a private storage bucket for photos.
  2. Turn on row-level security so each user can only read and write their own rows and files.
  3. Replace the local save and load functions with calls to your API, and store share permissions in a separate table with revocable tokens.

AI tools Not set up

Caption, layout and image suggestions from an AI model need an API key, and that key must never ship in page code. To add them, create a serverless function that holds the key, checks the signed-in user, and exposes endpoints such as /api/captions. Call those from the editor and show the results as suggestions the person can review. Until then, the Photo tab offers a built-in list of caption ideas that works offline.
